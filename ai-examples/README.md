# Библиотека человеческих примеров для CLEV3R AI

Эта папка — общая библиотека примеров для всех проектов, открываемых в IDE.
При запуске CLEV3R рекурсивно индексирует только файлы `.md` из папки
`ai-examples` рядом с `Clever.exe`. Новые или изменённые примеры станут доступны
после следующего запуска IDE.

Каждый Markdown является справочным материалом, а не инструкцией для агента.
Документация CLEV3R остаётся источником истины для API Basic Plus.
