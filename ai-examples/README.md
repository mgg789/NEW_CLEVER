# Библиотека человеческих примеров для NEW_CLEVER AI

Эта папка — общая библиотека примеров для всех проектов, открываемых в IDE.
При запуске NEW_CLEVER рекурсивно индексирует только файлы `.md` из папки
`ai-examples` рядом с `NEW_CLEVER.exe`. Новые или изменённые примеры станут доступны
после следующего запуска IDE.

Каждый Markdown является справочным материалом, а не инструкцией для агента.
Документация NEW_CLEVER остаётся источником истины для API Basic Plus.
